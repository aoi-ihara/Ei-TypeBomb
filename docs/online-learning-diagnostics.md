# オンライン学習の診断ログ

通常は回答・推薦の詳細ログを保存しません。推薦と実際の回答対象の不一致（`reconciled: true`）は、認証済み参加者から受け取った場合に常時記録します。

比較検証をするときだけ、対象のNodeサーバーの環境変数、またはWorkerの環境変数に `ETB_ONLINE_LEARNING_DIAGNOSTICS=1` を設定します。フロントエンドの再ビルドや公開環境変数の追加は不要です。Nodeは既存の `backend/server/logs/server.log`、WorkerはWorkersのログへ保存します。設定の変更・本番への反映は別途行ってください。

有効時には推薦、実際の出題、回答評価、未回答終了の要約を記録します。サーバーごとの推薦の受信・消費ログと、分散実行部の重複した単語通過ログは削除しています。接続やゲーム終了などの既存の運用ログは維持します。

## 回答ごとの項目

- `diagnosticVersion`: ログ形式（`online-learning-v2`）。
- `hintEvidenceVersion`: ヒント依存度の方式（`auto-hint-input-v1`）。共通の記憶モデルの版とは独立しています。
- `displayedHintCount`: 表示イベントの数。初期の重複プロンプト用ヒントも含みます。
- `hintCount`: 実際に正しい入力を支援した表示イベントの数。
- `revealedHintChars`: 実際の表示範囲の長さ。既存レイアウトの空白を含みます。
- `preHintCorrectChars`: 各位置が初めて表示された時点で、既に正しく入力されていた空白以外の文字数。位置ごとに一度だけ数えます。
- `assistedHintChars`: 表示時には未解決で、その後正しく入力した空白以外の位置数。リセット・再入力でも二重計上しません。
- `displayedFullAnswer`: 画面上で全範囲を表示したか。
- `answerWasFullyRevealed`: 学習評価上の全依存。全表示でも入力済みの部分があれば全依存とは限りません。
- `attemptKey`: 対戦・爆弾・ターンを結ぶキー。同じ単語が再提示されても区別できます。

既存の単語ID、スケジューラーのターン・理由、依存率、回答評価、再学習待ち件数も残します。回答本文やキー入力の文字列は診断ログに追加しません。

## 未回答終了

最新の進捗をブラウザ内だけで保持し、爆発・ゲーム終了・ターン変更・ゲーム中断・退出・画面離脱時に `kind: "unfinished"` と `endReason` を一度だけ送信します。成功済みの回答を未回答として再記録しません。通信断からの復帰や所有サーバー移行だけでは未回答終了にしません。

`elapsedMs` と文字数は最後に取得した進捗時点の値です。毎キーのサーバーログや進捗送信は追加しません。開始時と再認証時に送る `recall_started` は、座席が消えた後の終了要約を本人の回答に結びつけるための登録で、ログ自体は出力しません。サーバーは登録された単語・ターンに一致する終了要約だけを受け取り、登録を消費します。Workerでは登録をWebSocket attachmentに保持します。

未回答ログは観測用で、記憶状態や再学習キューを更新しません。送信は通常の接続を使うため、ページの強制終了や通信不能で配送できない場合があります。サーバーで確定した全失敗の集計としては扱わないでください。
